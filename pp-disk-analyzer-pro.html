Privacy Policy for Disk Analyzer Pro

Effective Date: September 5, 2026

MNIX TECH ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains our practices regarding the collection, use, and disclosure of information when you use the Disk Analyzer Pro desktop application (the "Software") for Windows and macOS.

1. Data Collection and Processing

Disk Analyzer Pro is designed as a strict local-first utility application. We prioritize your privacy by ensuring that your personal files and system data remain entirely on your device.

  • Local File Scanning: The Software scans your local storage drives, folders, and files to calculate sizes and generate visual storage maps. This process happens entirely locally on your machine. We do not transmit, upload, or collect your file names, file contents, folder structures, or storage metrics to any external servers.
  • System Monitoring Data: Features such as the System Monitor access real-time CPU and RAM usage statistics strictly for live display within the Software. This telemetry data is never logged, stored, or transmitted externally.
  • Application Uninstaller: The Software reads your locally installed applications to provide uninstaller functionality. This list is processed locally and is not shared with MNIX TECH or any third parties.

2. Data Storage

Any data saved by Disk Analyzer Pro is stored locally on your device's hard drive using secure local configuration files.

  • App Preferences: Your custom settings, such as excluded folders, theme preferences, and recent scan history, are stored locally on your machine to improve your user experience during subsequent launches.
  • No Cloud Storage: We do not maintain databases, cloud storage, or remote servers to host your user data. You have full control over your data, and uninstalling the Software will remove these local configuration files.

3. Third-Party Services

Disk Analyzer Pro utilizes standard web technologies and libraries to function, which may have limited interactions with third-party services strictly for rendering purposes:

  • Google Charts API: The Software uses Google Charts to render the Treemap visualization of your disk space. While the rendering library is loaded into the application, the local data (file paths and sizes) parsed by Disk Analyzer Pro is processed within the local environment and is not uploaded to Google's servers for processing.

4. Permissions Required

To function correctly, Disk Analyzer Pro requires the following operating system permissions:

  • File System Access: Required to read file sizes, directory structures, and execute file deletions (moving items to the Trash/Recycle Bin) strictly at your explicit command.
  • System Information Access: Required to display hardware monitoring statistics (CPU load, available RAM) and list installed applications.

5. Children's Privacy

The Software does not knowingly collect personally identifiable information from anyone under the age of 13. Because the Software does not transmit personal data back to MNIX TECH, we do not possess or store any information regarding the age of our users.

6. Changes to This Privacy Policy

We may update our Privacy Policy from time to time to reflect changes in our practices or for other operational, legal, or regulatory reasons. If we make material changes, we will notify you by updating the "Effective Date" at the top of this policy and, where appropriate, through in-app release notes.
